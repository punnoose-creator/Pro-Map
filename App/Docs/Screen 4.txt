Functionality & Behavior:

1. Data Fetching:
   - On screen load:
       → Call backend APIs
       → Fetch:
           - Total employees
           - Active employees count
           - Location logs count (today)
           - Work logs count (today)
           - Employee list

2. Employee List Interaction:
   - On click:
       → Navigate to Employee Detail Screen
       → Pass employee_id

3. Search:
   - Real-time filtering by:
       - Name
       - Email

4. Filter:
   - Filter employees by:
       - Active / Inactive
       - Date (last activity)
   - Update list dynamically

5. Status Logic:
   - Active:
       → If user has active work session
   - Inactive:
       → No active tracking

6. Last Location:
   - Fetch latest location from DB
   - Show readable area + city

7. Last Update:
   - Fetch latest work log timestamp

8. Analytics Cards:
   - Auto-refresh (optional every X seconds)
   - Or refresh on pull-down

---

Backend (MongoDB Logic):

Collections used:
- users
- location_logs
- work_logs

Example Queries:

1. Total Employees:
   db.users.countDocuments({ role: "employee" })

2. Active Employees:
   db.users.countDocuments({ isWorking: true })

3. Locations Tracked Today:
   db.location_logs.countDocuments({
      timestamp: { $gte: startOfDay }
   })

4. Work Updates Today:
   db.work_logs.countDocuments({
      timestamp: { $gte: startOfDay }
   })

5. Employee List:
   db.users.find({ role: "employee" })

6. Last Location:
   db.location_logs.find({ user_id })
      .sort({ timestamp: -1 })
      .limit(1)

7. Last Work Update:
   db.work_logs.find({ user_id })
      .sort({ timestamp: -1 })
      .limit(1)
